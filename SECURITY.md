# Security Policy

## Supported Versions

Only the latest `0.x` version is expected to receive fixes before the first
stable `1.0.0` release.

## Reporting a Vulnerability

Do not publish secrets, credentials, private keys, callback tokens, or real
message payloads in public issues. Report vulnerabilities through the repository
maintainer's private contact channel once a public repository exists.

## Native SDK Binaries

`WeComKit.MsgAudit` does not redistribute or download Tencent's official native
message audit SDK. Consumers are responsible for obtaining native binaries from
official channels and verifying their deployment.
